# 工作流 iOS 客户端实施计划

**目标：** 将 Flutter iPhone 客户端接入工作流草稿、行动中心、通知回执和真机验证。

**范围：** 使用现有 Material 3 与 Lucide 组件；新增工作流草稿页、单问题追问、确认/撤销、已信任类型和行动中心。不得把技术 DAG 或模型输出原文展示给用户。

**验收：** 文本和短语音均能创建工作流草稿；R2 始终确认；R1 自动创建显示十分钟撤销；本地通知和服务端动态更新不会重复；iPhone 真机完成三条闭环。

**任务：**

- [ ] 为 workflow draft API 建立认证 repository 与 fake 测试。
- [ ] 实现追问、业务化草稿确认和授权管理页面。
- [ ] 以待决策优先实现行动中心和工作流详情。
- [ ] 接入本地通知回执、离线动作队列和系统设置深链。
- [ ] 完成 Dynamic Type、深色模式、VoiceOver 和小屏测试。
- [ ] 在真机验证用药、有效期、智能出门，记录截图和失败降级结果。
