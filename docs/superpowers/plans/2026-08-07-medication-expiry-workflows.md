# 周期用药与有效期工作流实施计划

**目标：** 完成周期用药、药品有效期两个 R2 健康闭环，并保持 OCR 识别结果必须人工确认。

**范围：** 新增 MedicationPlan、MedicationOccurrence、服药动作和过期阈值规则；将现有药品批次作为有效期事实来源，不从 OCR 原文直接创建健康计划。

**验收：** R2 创建和剂量修改每次确认；未来 30 天用药实例可幂等物化；已服、跳过和稍后操作可追溯；药品日期修订会安全重排提醒；OCR 服务关闭时入口显示不可用而非失败后才提示。

**任务：**

- [ ] 写用药实例物化、时区、重复生成和动作幂等失败测试。
- [ ] 创建健康领域模型和认证动作 API。
- [ ] 实现周期用药 Runner、本地通知动作回执和稍后代次。
- [ ] 实现批次有效期阈值查询、状态变化去重与行动中心卡片。
- [ ] 增加 OCR capability 接口与 Flutter 入口状态同步。
- [ ] 跑健康、OCR、工作流与迁移全套回归。
