# 智能出门工作流实施计划

**目标：** 完成智能出门的路线、天气、日历选择与明确降级提醒闭环。

**范围：** 使用和风天气、高德路线和用户明确选择的 EventKit 事件；服务器只保存必要事件快照和外部 ID，不上传完整日历。

**验收：** 出门时间按路线与缓冲计算；路线失败退回最近成功估时或静态通勤时长；天气失败明确标记 unavailable；Provider 不可用仍产生基础提醒；所有密钥只在服务端。

**任务：**

- [ ] 写 Provider adapter 合约、超时、缓存和降级测试。
- [ ] 实现和风、高德 adapter 与加密配置读取。
- [ ] 实现智能出门 Runner 两次预检查、结果指纹和 Outbox 去重。
- [ ] 建立日历事件选择快照模型和最小同步 API。
- [ ] 增加天气/路线失败、路线变化和导航深链验收测试。
- [ ] 用测试账户做真实 Provider 冒烟并记录速率限制。
