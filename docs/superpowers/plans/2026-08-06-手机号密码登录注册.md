# 手机号密码登录注册实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为智能提醒 App 增加中国大陆手机号加密码的注册、登录、会话恢复、自动刷新、修改密码和退出闭环。

**Architecture:** Django 新增独立 `accounts` 模块，保留默认 User 并以 `PhoneIdentity` 维护 E.164 手机号；SimpleJWT 负责轮换与黑名单，组合 Bearer 认证器在迁移期兼容旧 DRF Token。Flutter 以统一认证 HTTP Client 替换各业务 API 中的固定 Token，使用 Keychain 存储令牌，并由根状态机在登录页与主界面间切换。

**Tech Stack:** Django 5.2、Django REST Framework、SimpleJWT blacklist、Redis cache、pytest-django、Flutter/Dart、`http`、`flutter_secure_storage`、Material 3。

class CompositeBearerAuthentication(BaseAuthentication):
    def authenticate(self, request):
        raw = get_bearer_value(request)
        if raw is None:
            return None
        if raw.count(".") == 2:
            return JWTAuthentication().authenticate(request)
        return LegacyBearerTokenAuthentication().authenticate(request)
